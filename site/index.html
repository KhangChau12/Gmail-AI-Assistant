Xếp thư vào đúng chỗ

Mỗi thư mới được đọc một lần, xếp vào danh mục bạn tự đặt, gắn mức ưu tiên và rút ra việc cần làm. Bạn đổi danh mục một lần, thư sau từ người đó tự vào đúng ô.

Cách hoạt động

Lần đầu nhập hộp thư. Từ đó chỉ tải thư mới.

BƯỚC 1
Chụp nhanh hộp thư

Chỉ lấy mã số và trạng thái đã đọc của từng thư — vài byte mỗi thư.

BƯỚC 2
Tải thư mới

Chỉ tải nội dung những thư chưa có, theo từng lô 25 thư.

BƯỚC 3
Khớp trạng thái

Đã đọc, gắn sao, lưu trữ hay xoá ở nơi khác đều được cập nhật lại.

BƯỚC 4
AI đọc một lần

Một lần gọi AI cho mỗi thư: danh mục, mức ưu tiên, hạn chót, việc cần làm và một câu tóm tắt.

Bàn phím trước tiên

Dọn hộp thư mà không cần chạm chuột.

Quyền riêng tư

Thư của bạn ở trên máy bạn.

Không có máy chủ trung gian

App chạy ở localhost, kết nối thẳng tới Gmail. Toàn bộ dữ liệu nằm trong một file SQLite — xoá file là xoá sạch.

Bạn chọn mô hình AI

Dùng OpenAI, hoặc trỏ sang mô hình chạy local như Ollama để không thư nào rời khỏi máy.

AI không tự gửi thư

Mọi thư AI viết đều là bản nháp. Chỉ bạn mới bấm được nút Gửi.

Chạy thử trong năm phút.

Cần Node.js 18+, một Gmail App Password và một OpenAI API key. Không cần tạo database hay tài khoản cloud.

Hướng dẫn đầy đủ trên GitHub
$ git clone https://github.com/KhangChau12/Gmail-AI-Assistant
$ cd Gmail-AI-Assistant && npm install
$ cp .env.example .env
# điền GMAIL_ADDRESS, GMAIL_APP_PASSWORD, OPENAI_API_KEY
$ npm run dev
✓ Sẵn sàng tại http://localhost:3000
